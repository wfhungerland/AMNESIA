# AMNESIA

Arbeitsrepo für das Paper **„Displacement Before Escalation: Technology Acquisition, Incumbent Response, and Convergence Limits in Four Late-Industrialising Economies“** (Ziel: *World Development*) und die angrenzenden Rhetorik-Indizes.

These: In vier Aufholfällen (Deutschland 1840–1914, Japan 1950–1990, Korea 1960–1997, China 1978–2024) verdrängt der Aufsteiger die Etablierten erst messbar von ihren Märkten; danach eskalieren Rhetorik und bindende Politik.

Stand: 20.11.2026. Verknüpft mit dem Ideenpool im Makrowolf (`hungerland-macro/macro`, `docs/ideen.md`, Block 8.9).
